# Category illustrations

Created for this project using the built-in image generation tool. PNG alpha has been preserved; the local previews were downsampled to 320 pixels for category thumbnails.

- `rumi.png`: Friendly clean 2D waist-up portrait of Rumi from KPop Demon Hunters; recognizable long purple braided ponytail, yellow cropped biker jacket, white top, bold purple outlines, minimal shading, transparent background, no text or symbols.
- `jj-mikey.png`: JJ in his red hoodie and Mikey as the upright green Minecraft turtle, square block geometry, smiling and waving together, clean 2D child-friendly art, transparent background, no text or scenery.
- `animals.png`: Lavender kitten and black-and-white panda sitting together, smiling, chunky purple outlines, flat soft colors, large simple shapes, transparent background, no text or scenery.

Coloring templates are separately authored vector artwork in `src/art.ts`; category illustrations are not used as fillable templates.
